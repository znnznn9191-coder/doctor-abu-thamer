# منصة أبو ثامر للأبحاث

هذه هي النسخة المحلية من منصة أبو ثامر للأبحاث، وهي منصة بحثية خاصة صممت للدكتور أبو ثامر بوصفه الباحث والمالك والمستخدم الأساسي. يدخل الدكتور موضوعات البحث التي يختارها، ثم تنظم المنصة تطويرها ومراجعتها الأكاديمية وتحفظها في «أبحاثي». تحفظ البيانات محلياً في SQLite ضمن واجهة عربية RTL.

## قاعدة المنتج الدائمة

المنصة ليست منصة طلابية، ولا تستهدف طلاب الجامعات أو أي فئة من المشاركين بوصفهم مستخدمين لها. يبقى الدكتور أبو ثامر صاحب المنصة والباحث الأساسي فيها. قد تتناول موضوعات البحث طلاباً أو جامعات أو معلّمين أو مرضى أو شركات أو غيرهم من مجتمع الدراسة؛ ولا يغيّر ذلك هوية مستخدم المنصة.

مسار الاستخدام هو: يدخل الدكتور موضوع البحث، وتطوره وحدات البحث الأكاديمي وتراجع الأدلة والمنهجية والتوثيق والبنية والكتابة، ثم تمر المراجعة والتصحيح والمراجعة الأكاديمية النهائية وبوابة الجاهزية، ويحفظ البحث في «أبحاثي». تبقى حقول المستوى الأكاديمي مثل جامعي ودراسات عليا وماجستير ودكتوراه وصفاً للبحث نفسه، ولا تصف مستخدم المنصة.

## المتطلبات
- Node.js 20 LTS (موصى به)
- VS Code
- الوصول إلى الإنترنت أثناء أول تثبيت للمكتبات

> ملاحظة مهمة: نسخة Node 24 قد تواجه مشكلة في تجميع مكتبة SQLite native، لذلك يوصى باستخدام Node 20 LTS للتشغيل المحلي.

## التشغيل المحلي
1. افتح VS Code.
2. افتح مجلد المشروع: `doctor-abu-thamer`.
3. افتح Terminal جديد.
4. انتقل إلى مجلد backend:

   ```bash
   cd backend
   ```

5. قم بتثبيت الاعتماديات:

   ```bash
   npm install
   ```

6. ابدأ الخادم المحلي:

   ```bash
   npm start
   ```

7. افتح المتصفح على العنوان التالي:

   ```text
   http://localhost:3000
   ```

8. عند الفتح، ستظهر الصفحة الرئيسية للمنصة مع البحث التجريبي الافتراضي داخل "أبحاثي".

## ما الذي يعمل الآن
- واجهة عربية RTL مع تصميم فاخر حديث.
- حفظ الأبحاث عبر SQLite محلياً.
- إنشاء/تحديث/حذف الأبحاث.
- إدارة الأقسام البحثية.
- إدارة المصادر والمراجع.
- تشغيل مراجعة داخلية للبحث عبر خطوات منطقية داخل الـ backend.
- خدمة frontend من Express على نفس المنفذ المحلي.

## بنية المشروع
- `backend/`: الخادم، API، SQLite، ومراحل المراجعة الداخلية.
- `frontend/`: واجهة المستخدم العامة.
- `architecture/`: ملفات التوثيق والمعمارية.
- `data/`: بيانات تجريبية.

## ملاحظات مهمة
- لا يتم عرض أسماء الوكلاء أو مزودي الخدمات أو أي تفاصيل داخلية في الواجهة العامة.
- لا تُستخدم أي واجهات AI حقيقية في هذه المرحلة.
- جميع العمليات الداخلية تظل داخل الـ backend.
- لا توجد مفاتيح أو بيانات حساسة في المشروع.

## التشغيل في VS Code
يمكنك أيضاً تشغيل المشروع من Terminal داخل مجلد `backend` مباشرة:

```bash
npm install
npm start
```

ثم افتح المتصفح على الرابط:

```text
http://localhost:3000
```
